# 🚗 Car Pricee Predcition

## 📌 Project Overview
This project focuses on predicting car prices using a **Linear Regression** machine learning model. The objective is to analyze different car features and understand how they influence the price of Ford vehicles. Using historical data, the model learns relationships between vehicle attributes and their market prices.

The project demonstrates a complete **machine learning workflow**, including data preprocessing, exploratory data analysis (EDA), model training, and evaluation.

---

## 📊 Dataset
The dataset contains information about Ford cars and several features that influence their selling price.

**Key Features:**
- Model – Name of the Ford car model  
- Year – Manufacturing year  
- Transmission – Type of transmission (Manual / Automatic / Semi-Auto)  
- Mileage – Distance traveled by the car  
- Fuel Type – Petrol, Diesel, or Hybrid  
- Tax – Road tax amount  
- MPG – Miles per gallon (fuel efficiency)  
- Engine Size – Engine capacity  
- Price – Selling price (target variable)

---

## ⚙️ Project Workflow

### 1️⃣ Data Loading
- Import dataset
- Understand data structure and variables

### 2️⃣ Data Cleaning
- Check for missing values
- Handle inconsistent or incorrect data

### 3️⃣ Exploratory Data Analysis (EDA)
- Visualize data distributions
- Identify relationships between features
- Correlation analysis

### 4️⃣ Data Preprocessing
- Encode categorical variables
- Feature selection
- Train-test split

### 5️⃣ Model Building
- Apply **Linear Regression**
- Train the model on the training dataset

### 6️⃣ Model Evaluation
Evaluate the model using:
- **Mean Absolute Error (MAE)**
- **Mean Squared Error (MSE)**
- **Root Mean Squared Error (RMSE)**
- **R² Score**

---

## 🧠 Machine Learning Model
The main algorithm used in this project is:

- **Linear Regression**

Linear Regression helps model the relationship between independent variables and a continuous target variable such as price.
